# 品牌规则的适配门槛

正式 `mac/rules.json` 目前为一个空 profiles 数组。不把模拟器规则、网上猜测或其他固件测试结果当作真实电视适配。

每个profile必须包含 manufacturer、model、fingerprint，全部与 `getprop` 返回值精确匹配；verified必须为true，并提供非空evidence记录，写明实机型号、固件、测试日期、组件用途、禁用后的遥控/网络/设置/输入源/重启检查及恢复结果。

packages每项包含 name（准确包名）、purpose（用户可理解的用途）、optional（只有true可选择）。组件在执行前再次检查，不允许保护规则、HOME入口、共享系统UID或持久进程被该规则覆盖。

示意结构（占位符不是可使用的品牌规则）：

```json
{
  "schema_version": 1,
  "profiles": [{
    "manufacturer": "精确厂商字符串",
    "model": "精确型号字符串",
    "fingerprint": "完整构建指纹",
    "verified": true,
    "evidence": "该设备的实机验收记录路径和日期",
    "packages": [{
      "name": "com.example.optional.recommend",
      "purpose": "可选推荐组件",
      "optional": true
    }]
  }]
}
```

固件更新后旧规则不匹配，退回仅扫描。新规则通过源码更新并重新构建Mac包；命令行可显式用 `--rules /已审核规则.json` 指定文件。没有在线规则更新、远程执行或静默下载适配表。
